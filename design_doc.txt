MUSIC COLAB: visualizing music artist collaboration
PHASE 1

1. Introduction & Goals
Project Overview: Provide an interactive network graph, visualizing collaborations between music artists, session artists and producers.

Target Users: casual fans

2. Scope: 
In Scope
display artist connections
search artists
show album metadata
filter by time period
Out of Scope
Music streaming
User accounts

5. Functional Requirements:
Core Features:
View network graph
Click artist to expand to albums and close ties
View connections between selected artists
Visualize connection strength
Search for an artist
Artist / Producer / Session artist tag visible
Show album details on click.
Youtube link for albums
User Flows: 
“User searches for ‘Miles Davis’ → Graph expands to show all collaborators and common albums”

6. Non Functional Requirements

8. API Design
Endpoints:

GET /album/{id} → album info + participants.
GET /band/{id}→ list of member artists.
